# Assets V5 Editorial B

- `brand/notamei.png`: monograma N existente do NotaMei, apenas recolorido para tinta `#1E1735`, papel `#FAF8F5` e verde `#28724B`. O mesmo bitmap é usado no ícone Android de maior resolução; todas as cinco densidades do launcher foram recoloridas preservando dimensões e transparência.
- `fonts/Inter.ttf`: Inter variável, família de corpo e controles.
- `fonts/PlayfairDisplay.ttf`: Playfair Display variável, família de títulos e balanço.
- As fontes e as licenças SIL Open Font License correspondentes são empacotadas no APK. Não há carregamento remoto de fontes em tempo de execução.

Fontes originais: repositório oficial `google/fonts`, diretórios `ofl/inter` e `ofl/playfairdisplay`. Os arquivos OFL mantêm os créditos e os termos de distribuição.

Esta pasta não contém PDFs de pesquisa, respostas individuais, dados financeiros ou credenciais.
